# Community code of conduct

TenantLens contributors must help maintain a welcoming, harassment-free community.
Participate with empathy, give actionable feedback, respect privacy, and assume good faith
while still holding security-sensitive work to a high standard.

Unacceptable behavior includes harassment, discriminatory language, threats, publishing
private information, exposing tenant data, or sustained disruption of project work.

Report conduct concerns privately to the repository maintainers through their verified
GitHub profiles. Maintainers may edit, reject, or remove contributions and temporarily or
permanently restrict participation when needed to protect the community.
